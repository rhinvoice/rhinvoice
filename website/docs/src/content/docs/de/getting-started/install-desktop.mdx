Rhinvoice gibt es auch als **normales Programm für Windows und Mac**: herunterladen, installieren, starten. Docker, Python oder einen Server brauchen Sie nicht. Die Datenbank ist eingebaut, Rhinvoice öffnet sich in einem eigenen Fenster und ist nur von diesem Computer aus erreichbar. Für einen Server, ein NAS oder mehrere Benutzer an verschiedenen Rechnern nehmen Sie die [Installation mit Docker](/docs/de/getting-started/installation/).

<Aside type="caution" title="Beta">
Das Programm ohne Docker ist neu und noch in der Testphase, Rhinvoice selbst ist in früher Entwicklung (0.x). Steuersätze und Regeln sind ohne Gewähr und ersetzen keine Steuerberatung. Richten Sie gleich nach der Installation das [Backup](/docs/de/operations/backup-desktop/) ein.
</Aside>

## Was Sie brauchen

- **Windows** 10 oder 11, 64 Bit, oder
- **einen Mac mit Apple-Chip** (M1 oder neuer) und macOS 12 oder neuer. Für Macs mit Intel-Prozessor gibt es noch kein Programm. Dort läuft Rhinvoice mit [Docker Desktop](/docs/de/getting-started/installation/).

## Herunterladen

Öffnen Sie die [neueste Version auf GitHub](https://github.com/rhinvoice/rhinvoice/releases/latest) und laden Sie unter *Assets* die Datei für Ihr System herunter:

- Windows: `Rhinvoice-Setup-<Version>.exe`
- Mac: `Rhinvoice-<Version>.dmg`

## Unter Windows installieren

<Steps>

1. Öffnen Sie `Rhinvoice-Setup-<Version>.exe` per Doppelklick.

2. **Die Warnung von Windows bestätigen.** Windows zeigt beim ersten Mal «Der Computer wurde durch Windows geschützt». Klicken Sie auf **Weitere Informationen** und dann auf **Trotzdem ausführen**. Die Schaltfläche erscheint erst nach dem Klick auf «Weitere Informationen».

3. Folgen Sie dem Setup. Es installiert Rhinvoice nur für Ihr Benutzerkonto nach `%LOCALAPPDATA%\Programs\Rhinvoice` und braucht keine Administratorrechte.

4. Starten Sie Rhinvoice über das Startmenü (oder direkt am Ende des Setups). Der erste Start richtet die Datenbank ein und dauert etwas länger.

</Steps>

## Auf dem Mac installieren

<Steps>

1. Öffnen Sie `Rhinvoice-<Version>.dmg` und ziehen Sie **Rhinvoice** in den Ordner **Programme**.

2. Öffnen Sie Rhinvoice aus dem Ordner Programme. macOS meldet beim ersten Mal, dass es Rhinvoice nicht überprüfen konnte, und öffnet es nicht. Klicken Sie auf **Fertig**.

3. **Rhinvoice erlauben.** Öffnen Sie  > **Systemeinstellungen** > **Datenschutz & Sicherheit** und scrollen Sie zum Abschnitt **Sicherheit**. Dort steht, dass Rhinvoice blockiert wurde. Klicken Sie auf **Dennoch öffnen**, bestätigen Sie mit Ihrem Anmeldepasswort und klicken Sie im nächsten Fenster nochmals auf **Dennoch öffnen**. Die Schaltfläche erscheint nur etwa eine Stunde nach dem Öffnungsversuch aus Schritt 2.

4. Rhinvoice startet. Ab jetzt öffnen Sie es wie jedes andere Programm, ohne Rückfrage.

</Steps>

<Aside title="Warum die Warnungen?">
Die Setups sind noch nicht mit einem kostenpflichtigen Zertifikat von Microsoft oder Apple signiert. Windows und macOS kennen den Herausgeber deshalb nicht und fragen einmal nach. Laden Sie Rhinvoice nur von der [GitHub-Seite des Projekts](https://github.com/rhinvoice/rhinvoice/releases) herunter.
</Aside>

## Erster Start

Rhinvoice öffnet ein eigenes Fenster und fragt nach dem ersten Benutzerkonto und Ihrer Firma, wie unter [Erster Start](/docs/de/getting-started/first-start/) beschrieben. Startet es ein zweites Mal, etwa durch einen Doppelklick zu viel, zeigt es das laufende Programm. Wenn Sie das Fenster schliessen, beendet sich Rhinvoice mitsamt seiner Datenbank.

## Wo Ihre Daten liegen

| | Programm | Daten (Datenbank, Einstellungen, Protokolle) |
|---|---|---|
| Windows | `%LOCALAPPDATA%\Programs\Rhinvoice` | `%LOCALAPPDATA%\Rhinvoice` |
| Mac | `/Applications/Rhinvoice.app` (im Finder: Programme) | `~/Library/Application Support/Rhinvoice` |

Der Datenordner gehört nur Ihrem Benutzerkonto. Updates und die Deinstallation lassen ihn unberührt: Rechnungen müssen zehn Jahre aufbewahrt werden. Was darin steht, sichert das [Backup](/docs/de/operations/backup-desktop/).

## Backup einrichten

Die Übersicht von Rhinvoice hat eine Checkliste mit dem Punkt **Backup einrichten**. Er führt zu *Einstellungen → Backup*, dort wählen Sie einen Ordner, am besten in OneDrive, Dropbox, iCloud Drive oder Google Drive, und bewahren den Wiederherstellungs-Schlüssel auf. Die Einzelheiten stehen unter [Backup im Programm für Windows und Mac](/docs/de/operations/backup-desktop/).

## Updates

Rhinvoice prüft selbst, ob es eine neue Version gibt. Dann erscheint ein Hinweis **Neue Version …** mit der Schaltfläche **Jetzt aktualisieren**. Das Update dauert etwa eine halbe Minute: Rhinvoice kopiert vorher die Datenbank, lädt die neue Version, prüft, dass sie unverändert angekommen ist, und startet neu. Startet die neue Version nicht, kommt automatisch die vorherige zurück, mit unveränderten Daten. Den Stand sehen Sie auch unter **Über Rhinvoice**.

Selten braucht eine neue Version ein neues Setup, etwa für eine neue Version der eingebauten Datenbank. Dann zeigt der Hinweis **Setup herunterladen**. Installieren Sie es über das bestehende Programm, Ihre Daten bleiben erhalten.

## Deinstallieren

- **Windows:** *Einstellungen → Apps → Installierte Apps → Rhinvoice → Deinstallieren*.
- **Mac:** Rhinvoice beenden und `Rhinvoice.app` aus dem Ordner Programme in den Papierkorb ziehen.

Ihre Daten bleiben dabei erhalten, auch für eine spätere Installation. Möchten Sie alles entfernen, löschen Sie danach den Datenordner aus der Tabelle oben. Bewahren Sie vorher die PDFs Ihrer ausgestellten Rechnungen oder ein Backup an einem anderen Ort auf.
