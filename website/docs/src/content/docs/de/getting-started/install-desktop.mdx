Rhinvoice gibt es auch als **normales Programm für Windows und Mac**: herunterladen, installieren, starten. Docker, Python oder einen Server brauchen Sie nicht. Die Datenbank ist eingebaut, Rhinvoice öffnet sich in einem eigenen Fenster und ist nur von diesem Computer aus erreichbar. Für einen Server, ein NAS oder mehrere Benutzer an verschiedenen Rechnern nehmen Sie die [Installation mit Docker](/docs/de/getting-started/installation/).

<Aside type="caution" title="Beta">
Das Programm ohne Docker ist neu und noch in der Testphase, Rhinvoice selbst ist in früher Entwicklung (0.x). Steuersätze und Regeln sind ohne Gewähr und ersetzen keine Steuerberatung. Richten Sie gleich nach der Installation das [Backup](/docs/de/operations/backup-desktop/) ein.
</Aside>

## Was Sie brauchen

- **Windows** 10 oder 11, 64 Bit, oder
- **einen Mac mit Apple-Chip** (M1 oder neuer) und macOS 12 oder neuer. Für Macs mit Intel-Prozessor gibt es noch kein Programm. Dort läuft Rhinvoice mit [Docker Desktop](/docs/de/getting-started/installation/).

## Herunterladen

Laden Sie die neueste Version für Ihr System herunter. Die Links führen immer zur aktuellen Version auf GitHub, wo Sie auch [alle Versionen und ihre Änderungen](https://github.com/rhinvoice/rhinvoice/releases) finden:

- Windows: [`Rhinvoice-Setup-Windows.exe`](https://github.com/rhinvoice/rhinvoice/releases/latest/download/Rhinvoice-Setup-Windows.exe)
- Mac: [`Rhinvoice-macOS.dmg`](https://github.com/rhinvoice/rhinvoice/releases/latest/download/Rhinvoice-macOS.dmg)

## Unter Windows installieren

<Steps>

1. Öffnen Sie `Rhinvoice-Setup-Windows.exe` per Doppelklick.

2. **Die Warnung von Windows bestätigen.** Windows zeigt beim ersten Mal «Der Computer wurde durch Windows geschützt». Klicken Sie auf **Weitere Informationen** und dann auf **Trotzdem ausführen**. Die Schaltfläche erscheint erst nach dem Klick auf «Weitere Informationen».

3. Folgen Sie dem Setup. Es installiert Rhinvoice nur für Ihr Benutzerkonto nach `%LOCALAPPDATA%\Programs\Rhinvoice` und braucht keine Administratorrechte.

4. Starten Sie Rhinvoice über das Startmenü (oder direkt am Ende des Setups). Der erste Start richtet die Datenbank ein und dauert etwas länger.

</Steps>

## Auf dem Mac installieren

<Steps>

1. Öffnen Sie `Rhinvoice-macOS.dmg` und ziehen Sie **Rhinvoice** in den Ordner **Programme**.

2. Öffnen Sie Rhinvoice aus dem Ordner Programme. Beim ersten Mal fragt macOS, ob Sie eine aus dem Internet geladene App öffnen möchten. Klicken Sie auf **Öffnen**. <Since version="0.8.6" />

3. Rhinvoice startet. Ab jetzt öffnen Sie es wie jedes andere Programm, ohne Rückfrage.

</Steps>

<Aside title="Warum warnt Windows?">
Die App für den Mac ist vom Hersteller signiert und von Apple beglaubigt (notarisiert): macOS hat sie geprüft und weiss, von wem sie stammt. <Since version="0.8.6" /> Das Setup für Windows ist noch nicht mit einem Zertifikat signiert. Windows kennt den Herausgeber deshalb nicht und fragt einmal nach. Laden Sie Rhinvoice nur von der [GitHub-Seite des Projekts](https://github.com/rhinvoice/rhinvoice/releases) herunter.

Die Programme für Windows und Mac sind ein Angebot in der Testphase, neben der Installation mit Docker. Sie werden gepflegt, solange sie genutzt werden. Auch das Setup für Windows wird signiert, dann entfällt die Warnung.
</Aside>

## Erster Start

Gleich nach dem Doppelklick zeigt eine Startkarte mit dem Rhinvoice-Logo, was gerade passiert, zum Beispiel «Datenbank wird gestartet …». Dann öffnet Rhinvoice ein eigenes Fenster und fragt nach dem ersten Benutzerkonto und Ihrer Firma, wie unter [Erster Start](/docs/de/getting-started/first-start/) beschrieben. Startet es ein zweites Mal, etwa durch einen Doppelklick zu viel, holt es sein offenes Fenster nach vorne, statt ein weiteres zu öffnen. Wenn Sie das Fenster schliessen, beendet sich Rhinvoice mitsamt seiner Datenbank.

## Wo Ihre Daten liegen

| | Programm | Daten (Datenbank, Einstellungen, Protokolle) |
|---|---|---|
| Windows | `%LOCALAPPDATA%\Programs\Rhinvoice` | `%LOCALAPPDATA%\Rhinvoice` |
| Mac | `/Applications/Rhinvoice.app` (im Finder: Programme) | `~/Library/Application Support/Rhinvoice` |

Der Datenordner gehört nur Ihrem Benutzerkonto. Updates und die Deinstallation lassen ihn unberührt: Rechnungen müssen zehn Jahre aufbewahrt werden. Was darin steht, sichert das [Backup](/docs/de/operations/backup-desktop/).

## Backup einrichten

Die Übersicht von Rhinvoice hat eine Checkliste mit dem Punkt **Backup einrichten**. Er führt zu *Einstellungen → Backup*, dort wählen Sie einen Ordner, am besten in OneDrive, Dropbox, iCloud Drive oder Google Drive, und bewahren den Wiederherstellungs-Schlüssel auf. Die Einzelheiten stehen unter [Backup im Programm für Windows und Mac](/docs/de/operations/backup-desktop/).

## Updates

Rhinvoice prüft selbst, ob es eine neue Version gibt. Dann erscheint ein Hinweis **Neue Version …** mit der Schaltfläche **Jetzt aktualisieren**. Rhinvoice fragt zuerst, ob es dafür neu starten darf: Speichern Sie vorher, woran Sie gerade arbeiten. Gibt es noch ungespeicherte Änderungen, sagt die Rückfrage das, und **Später** bringt Sie zurück. Das Update dauert etwa eine halbe Minute: Rhinvoice kopiert vorher die Datenbank, lädt die neue Version, prüft, dass sie unverändert angekommen ist, und startet neu. Startet die neue Version nicht, kommt automatisch die vorherige zurück, mit unveränderten Daten. Den Stand sehen Sie auch unter **Über Rhinvoice**; dort fragt **Nach Updates suchen** sofort nach.

Selten braucht eine neue Version ein neues Setup, etwa für eine neue Version der eingebauten Datenbank. Dann zeigt der Hinweis **… braucht ein neues Setup**. Auch das erledigt **Jetzt aktualisieren**: Rhinvoice lädt das Setup im Hintergrund, prüft es wie ein Update und fragt dann, ob es sich schliessen darf. Danach installiert das Setup die neue Version und startet Rhinvoice wieder, Ihre Daten bleiben erhalten. Auf dem Mac ersetzt Rhinvoice dabei die App im Programme-Ordner; klappt das nicht, öffnet sich das Setup, und Sie ziehen Rhinvoice selbst in *Programme*. Schlägt der Download fehl, führt **Setup selbst herunterladen** zur Datei. <Since version="0.8.2" />

Starten Sie ein Setup selbst, während Rhinvoice läuft, bittet das Setup unter Windows darum, Rhinvoice zuerst zu schliessen.

## Rhinvoice Beta für Testkandidaten

Bevor eine Version freigegeben wird, erscheint sie als Testkandidat. Für Windows und Mac kommt ein Testkandidat als **Rhinvoice Beta**: ein eigenes Programm, das Sie neben Rhinvoice installieren. Es hat einen eigenen Namen, eigene Verknüpfungen, einen eigenen Eintrag zum Deinstallieren und einen eigenen Datenordner (`%LOCALAPPDATA%\Rhinvoice Beta`, auf dem Mac `~/Library/Application Support/Rhinvoice Beta`). Die Daten von Rhinvoice berührt es nie. <Since version="0.8.1" /> Sein Icon ist das von Rhinvoice mit einer gelb-schwarz gestreiften Kante unten. <Since version="0.8.3" />

Laden Sie `Rhinvoice-Beta-Setup-Windows.exe` oder `Rhinvoice-Beta-macOS.dmg` beim Testkandidaten unter [GitHub Releases](https://github.com/rhinvoice/rhinvoice/releases) herunter und installieren Sie es wie oben beschrieben; unter Windows erscheint dieselbe Warnung. Unter Windows landet es in `%LOCALAPPDATA%\Programs\Rhinvoice Beta`, auf dem Mac heisst es `Rhinvoice Beta.app`. Rhinvoice Beta bekommt neuere Testkandidaten als Update angeboten, Rhinvoice selbst nur freigegebene Versionen. Das gilt auch für den nächsten Testkandidaten derselben Version, zum Beispiel `v0.8.4-rc.3` nach `v0.8.4-rc.2`; Rhinvoice Beta zeigt den Testkandidaten neben der Version an. Dafür braucht es einmal ein Setup ab Version 0.8.4. <Since version="0.8.4" /> Deinstallieren Sie es wie Rhinvoice.

<Aside type="caution">
Testkandidaten sind zum Testen da. Verwenden Sie Rhinvoice Beta mit Testdaten oder einer Kopie, nicht für die Rechnungen, die Sie verschicken.
</Aside>

## Ein Problem melden

In *Über Rhinvoice* (ein Klick auf die Version unten in der Navigation) steht der Link **Problem melden**. Er kopiert die Version, Ihr System und das Ende des Protokolls und führt zu einem neuen Fehlerbericht auf GitHub; Sie können die Angaben auch per Mail an hello@rhinvoice.com schicken. Rhinvoice verschickt nichts von selbst. Das Protokoll kann Namen von Kunden enthalten, schauen Sie also kurz darüber, bevor Sie es einfügen.

## Deinstallieren

- **Windows:** *Einstellungen → Apps → Installierte Apps → Rhinvoice → Deinstallieren*.
- **Mac:** Rhinvoice beenden und `Rhinvoice.app` aus dem Ordner Programme in den Papierkorb ziehen.

Ihre Daten bleiben dabei erhalten, auch für eine spätere Installation. Möchten Sie alles entfernen, löschen Sie danach den Datenordner aus der Tabelle oben (unter Windows samt dem Zwischenspeicher `cache` darin), auf dem Mac auch `~/Library/Caches/Rhinvoice`. Bewahren Sie vorher die PDFs Ihrer ausgestellten Rechnungen oder ein Backup an einem anderen Ort auf.
