faq:
  - q: Wie oft gibt es neue Versionen von Rhinvoice?
    a: Rhinvoice ist in der Beta (0.x) und erscheint oft, manchmal mehrmals pro Woche. Jede Version steht mit Datum auf dieser Seite und auf GitHub.
  - q: Welche Version habe ich?
    a: Die Version steht in der App unten in der Seitenleiste und im Fenster «Über Rhinvoice», zum Beispiel «v0.7.1». Auf der Anmeldeseite steht sie unter dem Formular.
  - q: Wie aktualisiere ich auf die neueste Version?
    a: Tragen Sie in der .env die neue Version ein und führen Sie docker compose pull und docker compose up -d aus. Die Datenbank wird beim Start automatisch angepasst. Machen Sie vorher ein Backup.
