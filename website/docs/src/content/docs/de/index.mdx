faq:
  - q: Ist Rhinvoice kostenlos?
    a: Ja. Rhinvoice ist Open Source unter der GNU Affero General Public License (AGPL) und darf kostenlos genutzt, verändert und weitergegeben werden. Es gibt keine kostenpflichtige Version und keinen gehosteten Dienst.
  - q: Für welche Länder ist Rhinvoice gemacht?
    a: Für Firmen in der Schweiz, in Liechtenstein, Deutschland und Österreich, mit den Steuersätzen, Pflichthinweisen und Zahlungs-QR-Codes des jeweiligen Landes. Ihre Kunden können überall sein.
  - q: Wo liegen meine Daten?
    a: Auf Ihrem eigenen Server oder Rechner. Rhinvoice läuft bei Ihnen, als Programm für Windows oder Mac oder mit Docker, und speichert alles in einer eigenen PostgreSQL-Datenbank. Daten gehen nur dann in eine Cloud, wenn Sie diese als Backup-Ziel wählen.

Rhinvoice ist ein kostenloses Open-Source-Rechnungsprogramm für kleine Firmen in der Schweiz, in Liechtenstein, Deutschland und Österreich. Es schreibt Angebote, Rechnungen, Stornorechnungen und Mahnungen mit den Steuerregeln, Zahlungs-QR-Codes und E-Rechnungsformaten des jeweiligen Landes. Es läuft als Programm unter Windows oder auf dem Mac, oder mit Docker auf Ihrem eigenen Server oder Rechner.
