Rhinvoice existe aussi comme **programme ordinaire pour Windows et Mac** : télécharger, installer, démarrer. Vous n’avez besoin ni de Docker, ni de Python, ni d’un serveur. La base de données est intégrée, Rhinvoice s’ouvre dans sa propre fenêtre et n’est accessible que depuis cet ordinateur. Pour un serveur, un NAS ou plusieurs personnes sur des ordinateurs différents, utilisez l’[installation avec Docker](/docs/fr/getting-started/installation/).

<Aside type="caution" title="Bêta">
Le programme sans Docker est nouveau et encore en test, et Rhinvoice lui-même en est à un stade précoce de développement (0.x). Les taux et les règles fiscales sont fournis sans garantie et ne remplacent pas un conseil fiscal. Mettez en place la [sauvegarde](/docs/fr/operations/backup-desktop/) juste après l’installation.
</Aside>

## Ce qu’il vous faut

- **Windows** 10 ou 11, 64 bits, ou
- **un Mac avec puce Apple** (M1 ou plus récent) et macOS 12 ou plus récent. Il n’existe pas encore de programme pour les Mac Intel; Rhinvoice y fonctionne avec [Docker Desktop](/docs/fr/getting-started/installation/).

## Télécharger

Téléchargez la version la plus récente pour votre système. Les liens mènent toujours à la dernière publication sur GitHub, où vous trouvez aussi [toutes les versions et leurs changements](https://github.com/rhinvoice/rhinvoice/releases) :

- Windows : [`Rhinvoice-Setup-Windows.exe`](https://github.com/rhinvoice/rhinvoice/releases/latest/download/Rhinvoice-Setup-Windows.exe)
- Mac : [`Rhinvoice-macOS.dmg`](https://github.com/rhinvoice/rhinvoice/releases/latest/download/Rhinvoice-macOS.dmg)

## Installer sur Windows

<Steps>

1. Double-cliquez sur `Rhinvoice-Setup-Windows.exe`.

2. **Si Windows demande.** Le setup est signé et Windows affiche son éditeur. Tant que le certificat est encore nouveau, SmartScreen peut quand même afficher une fois « Windows a protégé votre ordinateur »: cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**. <Since version="0.8.6" />

3. Suivez le setup. Il installe Rhinvoice uniquement pour votre compte utilisateur, dans `%LOCALAPPDATA%\Programs\Rhinvoice`, et ne demande pas de droits d’administrateur.

4. Démarrez Rhinvoice depuis le menu Démarrer (ou directement à la fin du setup). Le premier démarrage prépare la base de données et prend un peu plus de temps.

</Steps>

## Installer sur un Mac

<Steps>

1. Ouvrez `Rhinvoice-macOS.dmg` et faites glisser **Rhinvoice** dans **Applications**.

2. Ouvrez Rhinvoice depuis Applications. La première fois, macOS demande si vous voulez ouvrir une app téléchargée depuis Internet. Cliquez sur **Ouvrir**. <Since version="0.8.6" />

3. Rhinvoice démarre. Désormais, vous l’ouvrez comme n’importe quel autre programme, sans question.

</Steps>

<Aside title="Programmes signés">
Le setup pour Windows et l’app pour Mac sont signés par leur éditeur; l’app pour Mac est en plus notarisée par Apple, qui l’a vérifiée. <Since version="0.8.6" /> Windows SmartScreen juge un nouveau certificat d’après le nombre de téléchargements de ses programmes et peut donc demander une fois au début. Ne téléchargez Rhinvoice que depuis la [page GitHub du projet](https://github.com/rhinvoice/rhinvoice/releases).

Les programmes pour Windows et Mac sont une offre en phase de test, à côté de l’installation avec Docker. Ils sont maintenus aussi longtemps qu’ils sont utilisés.
</Aside>

## Premier démarrage

Juste après le double-clic, une carte de démarrage avec le logo de Rhinvoice montre ce qui se passe, par exemple « Démarrage de la base de données … ». Ensuite, Rhinvoice ouvre sa propre fenêtre et demande le premier compte utilisateur et votre entreprise, comme décrit sous [Premier démarrage](/docs/fr/getting-started/first-start/). Démarré une deuxième fois, par exemple à cause d’un double-clic de trop, il ramène sa fenêtre ouverte au premier plan au lieu d’en ouvrir une autre. Quand vous fermez la fenêtre, Rhinvoice s’arrête avec sa base de données.

## Où se trouvent vos données

| | Programme | Données (base de données, réglages, journaux) |
|---|---|---|
| Windows | `%LOCALAPPDATA%\Programs\Rhinvoice` | `%LOCALAPPDATA%\Rhinvoice` |
| Mac | `/Applications/Rhinvoice.app` | `~/Library/Application Support/Rhinvoice` |

Seul votre compte utilisateur peut ouvrir le dossier de données. Les mises à jour et la désinstallation n’y touchent pas : les factures doivent être conservées dix ans. La [sauvegarde](/docs/fr/operations/backup-desktop/) enregistre son contenu.

## Mettre en place la sauvegarde

La vue d’ensemble de Rhinvoice contient une liste de contrôle avec le point **Configurer la sauvegarde**. Il mène à *Paramètres → Sauvegarde*, où vous choisissez un dossier, de préférence dans OneDrive, Dropbox, iCloud Drive ou Google Drive, et conservez la clé de récupération. Les détails se trouvent sous [Sauvegardes dans le programme pour Windows et Mac](/docs/fr/operations/backup-desktop/).

## Mises à jour

Rhinvoice cherche lui-même les nouvelles versions. Un avis **Nouvelle version …** apparaît alors avec le bouton **Mettre à jour maintenant**. Rhinvoice demande d’abord s’il peut redémarrer : enregistrez avant ce sur quoi vous travaillez. S’il reste des modifications non enregistrées, la question le signale, et **Plus tard** vous ramène en arrière. La mise à jour prend environ une demi-minute : Rhinvoice copie d’abord la base de données, télécharge la nouvelle version, vérifie qu’elle est arrivée intacte et redémarre. Si la nouvelle version ne démarre pas, la précédente revient automatiquement, avec vos données inchangées. *À propos de Rhinvoice* indique aussi l’état; **Rechercher des mises à jour** y lance la vérification tout de suite.

Rarement, une nouvelle version demande un nouveau programme d’installation, par exemple pour une nouvelle version de la base de données intégrée. L’avis indique alors **… nécessite un nouveau programme d’installation**. **Mettre à jour maintenant** s’en charge aussi : Rhinvoice télécharge le programme d’installation en arrière-plan, le vérifie comme une mise à jour, puis demande s’il peut se fermer. Le programme d’installation installe ensuite la nouvelle version et redémarre Rhinvoice; vos données restent. Sur un Mac, Rhinvoice remplace l’app dans le dossier Applications; si cela échoue, le programme d’installation s’ouvre et vous glissez vous-même Rhinvoice dans *Applications*. Si le téléchargement échoue, **Télécharger vous-même le programme d’installation** mène au fichier. <Since version="0.8.2" />

Si vous lancez vous-même un programme d’installation pendant que Rhinvoice fonctionne, il vous demande sous Windows de fermer d’abord Rhinvoice.

## Rhinvoice Beta pour les versions candidates

Avant d’être publiée, une version paraît comme version candidate, pour les tests. Pour Windows et Mac, une version candidate arrive sous le nom de **Rhinvoice Beta**: un programme distinct, que vous installez à côté de Rhinvoice. Il a son propre nom, ses propres raccourcis, sa propre entrée de désinstallation et son propre dossier de données (`%LOCALAPPDATA%\Rhinvoice Beta`, sur un Mac `~/Library/Application Support/Rhinvoice Beta`). Il ne touche jamais aux données de Rhinvoice. <Since version="0.8.1" /> Son icône est celle de Rhinvoice, avec un bord rayé jaune et noir en bas. <Since version="0.8.3" />

Téléchargez `Rhinvoice-Beta-Setup-Windows.exe` ou `Rhinvoice-Beta-macOS.dmg` depuis la version candidate sur [GitHub releases](https://github.com/rhinvoice/rhinvoice/releases) et installez-le comme décrit plus haut. Sur Windows, il s’installe dans `%LOCALAPPDATA%\Programs\Rhinvoice Beta`, sur un Mac il s’appelle `Rhinvoice Beta.app`. Rhinvoice Beta se voit proposer les versions candidates plus récentes comme mises à jour; Rhinvoice lui-même uniquement les versions publiées. Cela vaut aussi pour la candidate suivante de la même version, par exemple `v0.8.4-rc.3` après `v0.8.4-rc.2`; Rhinvoice Beta affiche la candidate à côté de la version. Il faut pour cela installer une fois un setup de la version 0.8.4 ou plus récente. <Since version="0.8.4" /> Désinstallez-le comme Rhinvoice.

<Aside type="caution">
Les versions candidates servent aux tests. Utilisez Rhinvoice Beta avec des données de test ou une copie, pas pour les factures que vous envoyez.
</Aside>

## Signaler un problème

*À propos de Rhinvoice* (cliquez sur la version en bas de la navigation) contient le lien **Signaler un problème**. Il copie la version, votre système et la fin du journal, et ouvre un nouveau rapport de bug sur GitHub; vous pouvez aussi l’envoyer par e-mail à hello@rhinvoice.com. Rhinvoice n’envoie rien de lui-même. Le journal peut contenir des noms de clients : relisez ce que vous collez.

## Désinstaller

- **Windows :** *Paramètres → Applications → Applications installées → Rhinvoice → Désinstaller*.
- **Mac :** quittez Rhinvoice et faites glisser `Rhinvoice.app` depuis Applications dans la Corbeille.

Vos données restent, aussi pour une installation ultérieure. Pour tout supprimer, effacez ensuite le dossier de données du tableau ci-dessus (sous Windows, il contient aussi le `cache`), sur un Mac aussi `~/Library/Caches/Rhinvoice`. Conservez d’abord ailleurs les PDF de vos factures émises ou une sauvegarde.
