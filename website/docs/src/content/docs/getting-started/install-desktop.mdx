Rhinvoice also comes as a **regular program for Windows and Mac**: download, install, start. You need neither Docker, Python nor a server. The database is built in, Rhinvoice opens in a window of its own and can only be reached from this computer. For a server, a NAS or several people on different computers, use the [installation with Docker](/docs/getting-started/installation/).

<Aside type="caution" title="Beta">
The program without Docker is new and still being tested, and Rhinvoice itself is in early development (0.x). Tax rates and rules come without warranty and do not replace tax advice. Set up the [backup](/docs/operations/backup-desktop/) right after installing.
</Aside>

## What you need

- **Windows** 10 or 11, 64-bit, or
- **a Mac with Apple silicon** (M1 or newer) and macOS 12 or newer. There is no program for Intel Macs yet; there Rhinvoice runs with [Docker Desktop](/docs/getting-started/installation/).

## Download

Download the newest version for your system. The links always lead to the latest release on GitHub, where you also find [all versions and their changes](https://github.com/rhinvoice/rhinvoice/releases):

- Windows: [`Rhinvoice-Setup-Windows.exe`](https://github.com/rhinvoice/rhinvoice/releases/latest/download/Rhinvoice-Setup-Windows.exe)
- Mac: [`Rhinvoice-macOS.dmg`](https://github.com/rhinvoice/rhinvoice/releases/latest/download/Rhinvoice-macOS.dmg)

## Installing on Windows

<Steps>

1. Double-click `Rhinvoice-Setup-Windows.exe`.

2. **If Windows asks.** The setup is signed, and Windows shows its publisher. While the certificate is still new, SmartScreen may show "Windows protected your PC" once anyway: click **More info**, then **Run anyway**. <Since version="0.8.6" />

3. Follow the setup. It installs Rhinvoice for your user account only, into `%LOCALAPPDATA%\Programs\Rhinvoice`, and needs no administrator rights.

4. Start Rhinvoice from the Start menu (or right at the end of the setup). The first start sets up the database and takes a little longer.

</Steps>

## Installing on a Mac

<Steps>

1. Open `Rhinvoice-macOS.dmg` and drag **Rhinvoice** into **Applications**.

2. Open Rhinvoice from Applications. The first time, macOS asks whether you want to open an app downloaded from the internet. Click **Open**. <Since version="0.8.6" />

3. Rhinvoice starts. From now on you open it like any other program, without being asked.

</Steps>

<Aside title="Signed programs">
The setup for Windows and the app for Mac are signed by their developer; the Mac app is also notarized by Apple, which has checked it. <Since version="0.8.6" /> Windows SmartScreen judges a new certificate by how often its programs have been downloaded, so it may ask once at first. Only download Rhinvoice from the [project's GitHub page](https://github.com/rhinvoice/rhinvoice/releases).

The programs for Windows and Mac are an offer in its test phase, next to the installation with Docker. They are looked after for as long as they are used.
</Aside>

## First start

Right after the double-click a start card with the Rhinvoice logo shows what is happening, for example "Starting the database …". Then Rhinvoice opens its own window and asks for the first user account and your company, as described under [First start](/docs/getting-started/first-start/). Started a second time, for example by one double-click too many, it brings its open window to the front instead of opening another one. When you close the window, Rhinvoice ends together with its database.

## Where your data lives

| | Program | Data (database, settings, logs) |
|---|---|---|
| Windows | `%LOCALAPPDATA%\Programs\Rhinvoice` | `%LOCALAPPDATA%\Rhinvoice` |
| Mac | `/Applications/Rhinvoice.app` | `~/Library/Application Support/Rhinvoice` |

Only your user account can open the data folder. Updates and uninstalling leave it alone: invoices must be kept for seven to ten years, depending on the country. The [backup](/docs/operations/backup-desktop/) saves what it holds.

## Setting up the backup

The Rhinvoice overview has a checklist with the item **Set up backups**. It leads to *Settings → Backup*, where you choose a folder, preferably in OneDrive, Dropbox, iCloud Drive or Google Drive, and keep the recovery key. The details are under [Backups in the program for Windows and Mac](/docs/operations/backup-desktop/).

## Updates

Rhinvoice checks for new versions itself. Then a notice **New version …** appears with the button **Update now**. Rhinvoice first asks whether it may restart for it: save what you are working on first. If there are unsaved changes, the question says so, and **Later** takes you back. The update takes about half a minute: Rhinvoice copies the database first, downloads the new version, checks that it arrived unchanged and restarts. If the new version does not start, the previous one comes back automatically, with your data unchanged. *About Rhinvoice* shows the state too; **Check for updates** there asks right away.

Rarely a new version needs a new setup, for example for a new version of the built-in database. Then the notice says **… needs a new setup**. **Update now** takes care of that too: Rhinvoice downloads the setup in the background, checks it like an update and then asks whether it may close. The setup then installs the new version and starts Rhinvoice again; your data stays. On a Mac, Rhinvoice replaces the app in the Applications folder; if that does not work, the setup opens and you drag Rhinvoice into *Applications* yourself. If the download fails, **Download the setup yourself** leads to the file. <Since version="0.8.2" />

If you start a setup yourself while Rhinvoice runs, the setup on Windows asks you to close Rhinvoice first.

## Rhinvoice Beta for release candidates

Before a version is released, it is published as a release candidate for testing. For Windows and Mac a candidate comes as **Rhinvoice Beta**: a separate program that you install beside Rhinvoice. It has its own name, shortcuts and uninstall entry, and its own data folder (`%LOCALAPPDATA%\Rhinvoice Beta`, on a Mac `~/Library/Application Support/Rhinvoice Beta`). It never touches the data of Rhinvoice. <Since version="0.8.1" /> Its icon is Rhinvoice's with a yellow and black striped edge at the bottom. <Since version="0.8.3" />

Download `Rhinvoice-Beta-Setup-Windows.exe` or `Rhinvoice-Beta-macOS.dmg` from the candidate on [GitHub releases](https://github.com/rhinvoice/rhinvoice/releases) and install it as described above. On Windows it goes to `%LOCALAPPDATA%\Programs\Rhinvoice Beta`, on a Mac it is `Rhinvoice Beta.app`. Rhinvoice Beta is offered newer candidates as updates; Rhinvoice itself is only offered released versions. That includes the next candidate of the same version, for example `v0.8.4-rc.3` after `v0.8.4-rc.2`; Rhinvoice Beta shows the candidate beside the version. It needs a setup of version 0.8.4 or later once. <Since version="0.8.4" /> Uninstall it like Rhinvoice.

<Aside type="caution">
Candidates are for testing. Use Rhinvoice Beta with test data or a copy, not for the invoices you send.
</Aside>

## Reporting a problem

*About Rhinvoice* (click the version at the foot of the navigation) has the link **Report a problem**. It copies the version, your system and the end of the log, and leads to a new bug report on GitHub; you can also send it by mail to hello@rhinvoice.com. Rhinvoice sends nothing by itself. The log can contain names of customers, so look over what you paste.

## Uninstalling

- **Windows:** *Settings → Apps → Installed apps → Rhinvoice → Uninstall*.
- **Mac:** quit Rhinvoice and drag `Rhinvoice.app` from Applications to the Trash.

Your data stays, also for a later installation. To remove everything, delete the data folder from the table above afterwards (on Windows it also holds the `cache`), on a Mac also `~/Library/Caches/Rhinvoice`. Keep the PDFs of your issued invoices or a backup somewhere else first.
