faq:
  - q: How often are there new versions of Rhinvoice?
    a: Rhinvoice is in beta (0.x) and is released often, sometimes several times a week. Every version is listed with its date on this page and on GitHub.
  - q: Which version do I have?
    a: The version is shown in the app at the bottom of the sidebar and in the "About Rhinvoice" window, for example "v0.7.4". The login page shows it below the form.
  - q: How do I update to the newest version?
    a: Set the new version in .env and run docker compose pull and docker compose up -d. The database is updated automatically at the start. Make a backup first.
