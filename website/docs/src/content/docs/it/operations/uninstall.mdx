Per rimuovere Rhinvoice, esegua `docker compose down --volumes --rmi all` nella sua cartella ed elimini la cartella. Questo cancella definitivamente tutte le fatture, i clienti e le impostazioni, quindi prima conservi i PDF delle Sue fatture emesse o un backup al di fuori di Docker.

<Aside type="caution" title="Prima conservi le Sue fatture">
Le fatture emesse vanno di solito conservate per dieci anni (Svizzera: art. 958f CO, Germania: § 147 AO, Austria: § 132 BAO). Rimuovere Rhinvoice le cancella definitivamente.
</Aside>

## 1. Un ultimo backup

Se ha configurato i backup ([Backup e ripristino](/docs/it/operations/backup/)), ne faccia un ultimo:

```bash
docker compose exec backup rhinvoice-backup backup   # un ultimo backup, se configurato (backup.md)
```

## 2. Rimuovere container, dati e immagini

Nella cartella con `compose.yml` e `.env`:

```bash
docker compose down --volumes --rmi all    # container, rete, volumi di dati e immagini
cd .. && rm -r rhinvoice                   # compose.yml e .env (contiene la password del database)
```

`--volumes` cancella il database (`rhinvoice_db-data`) e i volumi di backup (`rhinvoice_backup-*`), compreso l’accesso salvato a Dropbox o Google Drive. I backup nel volume locale predefinito se ne vanno con essi; una cartella impostata come `BACKUP_LOCAL_DIR` e le destinazioni S3, SFTP e cloud non vengono toccate. Le elimini Lei quando non le servono più.

`--rmi all` rimuove le immagini di Rhinvoice, del suo backup, di PostgreSQL e di Gotenberg. Docker mantiene un’immagine che un altro progetto usa ancora e lo segnala; va bene così.

### Un’installazione con un proprio nome

Per un’installazione con un proprio nome di progetto, esegua il comando nella sua cartella se il nome è nel suo `.env` (`COMPOSE_PROJECT_NAME`), altrimenti lo aggiunga: `docker compose -p rhinvoice-try down --volumes --rmi all`. I controlli qui sotto cercano allora quel nome invece di `rhinvoice`.

## 3. Controllare che non resti nulla

```bash
docker ps -a --filter name=rhinvoice                   # container: nessuno
docker volume ls --filter name=rhinvoice               # volumi: nessuno
docker image ls | grep -E "rhinvoice|gotenberg"        # immagini: nessuna
```

Se qualcosa è ancora elencato, per esempio immagini di versioni precedenti che `--rmi all` non conosce:

```bash
docker image rm $(docker image ls -q --filter "reference=ghcr.io/rhinvoice/*")
docker volume rm rhinvoice_db-data                     # uno alla volta, come elencati
```

Docker Desktop mostra lo stesso in *Containers*, *Images* e *Volumes*, ognuno con un pulsante per eliminare.

## Solo fermare

Per mettere in pausa Rhinvoice senza perdere dati, lo fermi invece di rimuoverlo:

```bash
docker compose down          # fermare; i dati restano nel volume "rhinvoice_db-data"
docker compose up -d         # riavviare, con tutti i dati
```
