To remove Rhinvoice, run `docker compose down --volumes --rmi all` in its folder and delete the folder. This deletes all invoices, customers and settings for good, so keep the PDFs of your issued invoices or a backup outside of Docker first.

<Aside type="caution" title="Keep your invoices first">
Issued invoices usually have to be kept for ten years (Switzerland: Art. 958f CO, Germany: § 147 AO, Austria: § 132 BAO). Removing Rhinvoice deletes them for good.
</Aside>

## 1. A last backup

If you set up backups ([Backup and restore](/docs/operations/backup/)), make a last one:

```bash
docker compose exec backup rhinvoice-backup backup   # a last backup, if you set one up (backup.md)
```

## 2. Remove containers, data and images

In the folder with `compose.yml` and `.env`:

```bash
docker compose down --volumes --rmi all    # containers, network, data volumes and images
cd .. && rm -r rhinvoice                   # compose.yml and .env (holds the database password)
```

`--volumes` deletes the database (`rhinvoice_db-data`) and the backup volumes (`rhinvoice_backup-*`), including the stored Dropbox or Google Drive access. Backups in the default local volume go with them; a folder set as `BACKUP_LOCAL_DIR`, S3, SFTP and cloud targets are not touched. Delete those yourself when you no longer need them.

`--rmi all` removes the images of Rhinvoice, its backup, PostgreSQL and Gotenberg. Docker keeps an image that another project still uses and says so; that is fine.

### An installation with a name of its own

For an installation with its own project name, run the command in its folder when the name is in its `.env` (`COMPOSE_PROJECT_NAME`), else add it: `docker compose -p rhinvoice-try down --volumes --rmi all`. The checks below then look for that name instead of `rhinvoice`.

## 3. Check that nothing is left

```bash
docker ps -a --filter name=rhinvoice                   # containers: none
docker volume ls --filter name=rhinvoice               # volumes: none
docker image ls | grep -E "rhinvoice|gotenberg"        # images: none
```

If something is still listed, e.g. images of older versions that `--rmi all` does not know:

```bash
docker image rm $(docker image ls -q --filter "reference=ghcr.io/rhinvoice/*")
docker volume rm rhinvoice_db-data                     # one by one, as listed
```

Docker Desktop shows the same under *Containers*, *Images* and *Volumes*, each with a delete button.

## Only stopping

To pause Rhinvoice without losing data, stop it instead:

```bash
docker compose down          # stop; the data stays in the volume "rhinvoice_db-data"
docker compose up -d         # start again, with all data
```
