Funktionen

Alles, womit ein kleines Unternehmen Rechnungen schreibt

  • Angebote, Rechnungen, StornosLive-Vorschau, Nummern ohne Lücken, ausgestellte Dokumente unveränderlich
  • Steuerfälle pro LandInland, Reverse Charge, innergemeinschaftlich, Export, Kleinunternehmer
  • Waren und Dienstleistungensauber getrennt, auch auf gemischten Rechnungen
  • Swiss QR-Rechnung und GiroCodeder richtige Code für Währung und Kunde, auf das gewählte Konto
  • ZUGFeRD und XRechnunggeprüft mit KoSIT und Mustang
  • Mahnwesendrei Stufen, Gebühren, neue Fristen
  • Wiederkehrende Rechnungenmonatlich bis jährlich, als Entwurf, ausgestellt oder versendet
  • Versand per E-Mailüber den eigenen Mailserver
  • Umzug aus dem alten ProgrammKunden, Artikel und alte Rechnungen mit Original-PDF übernehmen
  • Backupsverschlüsselt mit restic, nach S3, SFTP, Dropbox oder Google Drive
  • Tastatur zuerst⌘K, Tastenkürzel, hell und dunkel
  • Auf dem HandyStatus prüfen, als bezahlt markieren, PDF teilen

Docker

Auf dem eigenen Laptop mit Docker Desktop (Mac, Windows, Linux), einem NAS, einem Raspberry Pi oder einem Server. Auch fürs Team.

Docker-Befehle ↓

Beta · Kostenlos und Open Source · Signierte Setups, die Mac-App von Apple beglaubigt (so geht’s).

Mit Docker installieren

# ein eigener Ordner
mkdir rhinvoice && cd rhinvoice

# Compose-Datei und Einstellungen
curl -fsSLO https://raw.githubusercontent.com/rhinvoice/rhinvoice/main/deploy/compose.yml
curl -fsSL https://raw.githubusercontent.com/rhinvoice/rhinvoice/main/.env.example -o .env

# in .env POSTGRES_PASSWORD auf einen langen Zufallswert setzen, dann starten
docker compose pull
docker compose up -d

# http://rhinvoice.localhost:8000 öffnen, beim ersten Besuch den ersten Benutzer anlegen

# optional, neben anderen Installationen: eigener Name und eigener Port
# (in .env: RHINVOICE_PORT=8100, danach bei jedem docker-compose-Befehl -p rhinvoice-test angeben)
docker compose -p rhinvoice-test up -d

# optional, nur auf dem eigenen Laptop: die kurze Adresse http://rhinvoice:8000
echo "127.0.0.1 rhinvoice" | sudo tee -a /etc/hosts
# und in .env: RHINVOICE_COOKIE_SECURE=false, dann nochmals docker compose up -d

Auf einem Server: HTTPS und Backup, siehe Installationsanleitung.
