Fonctions

Tout ce qu’il faut à une petite entreprise pour facturer

  • Offres, factures, annulationsaperçu en direct, numéros sans lacunes, documents émis verrouillés
  • Traitement fiscal par paysnational, autoliquidation (reverse charge), intracommunautaire, exportation, petite entreprise
  • Biens et servicesséparés, même sur les factures mixtes
  • Facture QR suisse et code QR EPCle bon code selon la monnaie et le client
  • ZUGFeRD et XRechnungvalidés avec KoSIT et Mustang
  • Rappelstrois niveaux, frais, nouveaux délais
  • Factures récurrentesde mensuelles à annuelles, en brouillon, émises ou envoyées
  • Envoi par e-mailpar votre propre serveur de messagerie
  • Migration depuis votre ancien programmeclients, articles et anciennes factures avec leurs PDF originaux
  • Sauvegardeschiffrées avec restic, vers S3, SFTP, Dropbox ou Google Drive
  • Clavier d’abord⌘K, raccourcis, clair et sombre
  • Sur le smartphonevérifier le statut, marquer comme payée, partager le PDF

Gratuit, et ça le restera

Open source, sans version payante prévue

Aucun service hébergé prévu

Rhinvoice peut être utilisé, modifié et partagé gratuitement sous la licence AGPL. Il n’est pas prévu d’en faire un service payant.

Vous le voulez hébergé?

Dites-le-nous dans les discussions GitHub. Si suffisamment de sponsors se réunissent pour couvrir les frais d’exploitation, un Rhinvoice hébergé est envisageable.

Installation

Prêt en cinq minutes.

Avec un programme d’installation sous Windows ou Mac, ou avec Docker sur votre propre ordinateur portable, un NAS, un Raspberry Pi ou un serveur.

Windows

Windows 10 et 11. Un programme d’installation avec une entrée dans le menu Démarrer; les mises à jour arrivent dans le programme.

Mac

macOS 12 ou plus récent, Apple silicon. Glissez-le dans Applications; les mises à jour arrivent dans le programme.

Télécharger pour Mac

Docker

Sur votre propre ordinateur portable avec Docker Desktop (Mac, Windows, Linux), un NAS, un Raspberry Pi ou un serveur. Aussi pour une équipe.

Commandes Docker ↓

Bêta · Gratuit et open source · Les programmes d’installation ne sont pas encore signés : Windows et macOS demandent une fois avant de les ouvrir (comment les ouvrir).

Installer avec Docker

# un dossier à part
mkdir rhinvoice && cd rhinvoice

# le fichier compose et les réglages
curl -fsSLO https://raw.githubusercontent.com/rhinvoice/rhinvoice/main/deploy/compose.yml
curl -fsSL https://raw.githubusercontent.com/rhinvoice/rhinvoice/main/.env.example -o .env

# dans .env, mettre POSTGRES_PASSWORD sur une longue valeur aléatoire, puis démarrer
docker compose pull
docker compose up -d

# ouvrir http://rhinvoice.localhost:8000, la première visite crée le premier utilisateur

# facultatif, à côté d’autres installations : un nom et un port à part
# (dans .env : RHINVOICE_PORT=8100, puis ajouter -p rhinvoice-test à chaque commande docker compose)
docker compose -p rhinvoice-test up -d

# facultatif, seulement sur votre propre ordinateur : l’adresse courte http://rhinvoice:8000
echo "127.0.0.1 rhinvoice" | sudo tee -a /etc/hosts
# et dans .env : RHINVOICE_COOKIE_SECURE=false, puis relancer docker compose up -d

Sur un serveur : HTTPS et sauvegardes, voir le guide d’installation.
