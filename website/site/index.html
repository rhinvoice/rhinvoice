Invoicing for Switzerland, Liechtenstein, Germany and Austria.

Features

Everything a small business invoices with

  • Quotes, invoices, cancellationslive preview, numbers without gaps, issued documents locked
  • Tax treatment by countrydomestic, reverse charge, intra-Community, export, small business
  • Goods and serviceskept apart, also on mixed invoices
  • Swiss QR-bill and EPC QRthe right code for the currency and the customer
  • ZUGFeRD and XRechnungvalidated with KoSIT and Mustang
  • Remindersthree levels, fees, new deadlines
  • Recurring invoicesmonthly to yearly, as draft, issued or sent
  • Sending by e-mailthrough your own mail server
  • ImportCSV and Excel with column mapping and test run
  • Backupsencrypted with restic, to S3, SFTP, Dropbox or Google Drive
  • Keyboard first⌘K, shortcuts, light and dark
  • On the phonecheck status, mark as paid, share the PDF

Install

Running in five minutes.

On a server, a NAS, a Raspberry Pi or your own laptop with Docker Desktop (macOS, Windows, Linux).

# a folder of its own
mkdir rhinvoice && cd rhinvoice

# the compose file and the settings
curl -fsSLO https://raw.githubusercontent.com/rhinvoice/rhinvoice/main/deploy/compose.yml
curl -fsSL https://raw.githubusercontent.com/rhinvoice/rhinvoice/main/.env.example -o .env

# in .env, set POSTGRES_PASSWORD to a long random value, then start
docker compose up -d

# open http://rhinvoice.localhost:8000, the first visit sets up the first user

# optional, only on your own laptop: the short address http://rhinvoice:8000
echo "127.0.0.1 rhinvoice" | sudo tee -a /etc/hosts
# and in .env: RHINVOICE_COOKIE_SECURE=false, then docker compose up -d again

On a server: HTTPS and backups, see the install guide.
