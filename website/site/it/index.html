Tutto ciò che serve a una piccola impresa per fatturare

  • Offerte, fatture, stornianteprima in tempo reale, numeri senza lacune, documenti emessi bloccati
  • Trattamento fiscale per paesenazionale, inversione contabile (reverse charge), intracomunitario, esportazione, piccola impresa
  • Beni e servizitenuti separati, anche nelle fatture miste
  • Fattura QR svizzera e codice QR EPCil codice giusto per la valuta e il cliente
  • ZUGFeRD e XRechnungconvalidati con KoSIT e Mustang
  • Sollecititre livelli, spese, nuovi termini
  • Fatture ricorrentida mensili ad annuali, come bozza, emesse o inviate
  • Invio per e-mailtramite il proprio server di posta
  • Migrazione dal programma precedenteclienti, articoli e fatture precedenti con i loro PDF originali
  • Backupcifrati con restic, su S3, SFTP, Dropbox o Google Drive
  • Prima la tastiera⌘K, scorciatoie, chiaro e scuro

Open source, senza versione a pagamento prevista

Nessun servizio in hosting previsto

Rhinvoice può essere usato, modificato e condiviso gratuitamente secondo la licenza AGPL. Non è previsto di trasformarlo in un servizio a pagamento.

Lo preferisce in hosting?

Ce lo dica nelle discussioni su GitHub. Se abbastanza sponsor si uniscono per coprire i costi di gestione, un Rhinvoice in hosting è pensabile.

Installazione

Pronto in cinque minuti.

Con un programma di installazione su Windows o Mac, oppure con Docker sul proprio portatile, un NAS, un Raspberry Pi o un server.

Windows

Windows 10 e 11. Un programma di installazione con una voce nel menu Start; gli aggiornamenti arrivano nel programma.

Download per Windows

Mac

macOS 12 o successivo, Apple silicon. Lo trascini in Applicazioni; gli aggiornamenti arrivano nel programma.

Download per Mac

Docker

Sul proprio portatile con Docker Desktop (Mac, Windows, Linux), un NAS, un Raspberry Pi o un server. Anche per un team.

Comandi Docker ↓

Beta · Gratuito e open source · L’app per Mac è notarizzata da Apple; il programma di installazione per Windows non è ancora firmato, quindi Windows chiede una volta prima di aprirlo (come aprirli).

Installare con Docker

# una cartella apposita
mkdir rhinvoice && cd rhinvoice

# il file compose e le impostazioni
curl -fsSLO https://raw.githubusercontent.com/rhinvoice/rhinvoice/main/deploy/compose.yml
curl -fsSL https://raw.githubusercontent.com/rhinvoice/rhinvoice/main/.env.example -o .env

# in .env impostare POSTGRES_PASSWORD su un valore casuale lungo, poi avviare
docker compose pull
docker compose up -d

# aprire http://rhinvoice.localhost:8000, la prima visita crea il primo utente

# facoltativo, accanto ad altre installazioni: un nome e una porta propri
# (in .env: RHINVOICE_PORT=8100, poi aggiungere -p rhinvoice-test a ogni comando docker compose)
docker compose -p rhinvoice-test up -d

# facoltativo, solo sul proprio computer: l’indirizzo breve http://rhinvoice:8000
echo "127.0.0.1 rhinvoice" | sudo tee -a /etc/hosts
# e in .env: RHINVOICE_COOKIE_SECURE=false, poi di nuovo docker compose up -d

Su un server: HTTPS e backup, vedere la guida all’installazione.
